# simple.malahim.dev

A minimal, single-file HTML version of my portfolio. No frameworks, no build step, just plain HTML and CSS.

**Live:** [https://simple.malahim.dev](https://simple.malahim.dev)
**Full portfolio:** [https://malahim.dev](https://malahim.dev)

## Why this exists

My main site at [malahim.dev](https://malahim.dev) is the full portfolio. This one is a lightweight, dependency-free version built to be fast, easy to read, and simple to maintain. It also ships structured data (`/data.json`).

## Stack

0 frameworks. Pure HTML and CSS. Deployed on GitHub Pages.
